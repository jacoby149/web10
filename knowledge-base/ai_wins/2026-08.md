# August 2026 Improvements

This records improvements dated August 14-31, after AI Use Theory was introduced in #615 (`33048bf7a`, Git date 14.08.2026), not measured productivity gains or proof that every change followed the theory.

Dates use the changelog, not commit or merge dates; known differences are listed below the table. PR numbers were matched against dated Git history; `not recorded` means no matching PR number was verified. Source links name the changelog version and retain commit references.

`fix` means a repair; `feature` means a new capability, including high-impact app UI, written guidance or test coverage; `evolutionary` means a substantial evolution of existing backend or shared mechanisms; and `revolutionary` means a fundamental whole-system, backend or human-computer interaction change that makes it almost unrecognizable. Labels are conservative: impact or a new screen alone does not make a revolution. KB-only decisions classify the written change, not shipped implementation. `Changed` lists only evidenced KB, code and tests changes. KB includes useful written guidance and decisions, not routine changelog entries or plan ticks; tests means test files changed, not merely that an existing suite ran.

The original MongoDB-to-ClickHouse rebuild predates August 14 and is excluded, as is September's later removal of remaining Mongo/FerretDB dependencies. The August migration rows concern leftover dependencies and account-migration tools, not another database rebuild.
