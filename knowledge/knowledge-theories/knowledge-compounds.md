# Knowledge Compounds

Knowledge isn't linear — it compounds.

## The Theory

Each piece of documented knowledge has two values:
- **Intrinsic**: what it teaches on its own
- **Relational**: what it unlocks by connecting to other knowledge

The relational value grows exponentially as the knowledge base expands. A new doc that links to 10 existing docs is worth more than 10 isolated docs.

## Implications

- Link aggressively. Every new doc should reference at least 3 existing ones.
- Maintain a navigation index. The README at each level is the entry point.
- Prune dead ends. Docs with no inbound or outbound links are knowledge debt.
