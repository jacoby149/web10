Two fixes, both important: (1) **the API stopped blocking the event loop.** Every v3 endpoint (and the `/ready` health check) was `async def` but did purely synchronous work — a blocking `clickhouse_connect` call — so each request held the single-threaded asyncio loop for the duration of its ClickHouse round-trip, and the popup's burst of ~6 concurrent calls (`list`/`list`/`manages`/`profile`/`admin`/`ready`) got *serialized*: total time ≈ the sum of all the round-trips, not the max.
