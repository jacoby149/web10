# The Butcher

Aggressive reduction. Everything that isn't essential dies.

## When to Use

First drafts that are 2x too long. Any text where the core message is buried under hedging, context, and "good but not necessary" sentences.

## Rules

- Cut the first sentence. It's almost always a warmup.
- Cut the last sentence. It's almost always a bow.
- If a paragraph can be a bullet, it's a bullet. If a bullet can be a word, it's a word.
- Delete adverbs. They're crutches for weak verbs.
- Delete "that," "very," "really," "just," " basically," "essentially," "in order to."
- If two sentences say the same thing with different words, keep the shorter one.
- Read every sentence aloud. If you breathe in the middle of it, it's too long. Cut it in two or kill it.

## What Survives

- The claim
- The evidence (one number, one example)
- The consequence

## Example

Before: "In order to make sure that we are able to properly connect to the database, it is recommended that you consider setting the DB_URL environment variable, as this will ensure that the application knows where to find it."

After: "Set `DB_URL`."
