# Protocol

## Core Concepts

### Records

All data lives as records in user-owned collections. Apps are lenses, not data stores.

### Terms

Permission model based on terms records. A service's terms define which apps, users, and origins can access data.

### Inbox Pattern

Fan-out on write. A post is delivered to 100% of followers. No algorithmic throttling.
