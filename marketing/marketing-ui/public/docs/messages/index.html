Messages

A DM-style demo: send messages between web10 users. Each conversation is a group — the first message to someone sets up the DM group, after that it's reused (no popup). Messages are documents attached to the group; members discover them via membership. When both parties are online, a message is also delivered in real time over a WebRTC P2P data channel — the group stays the source of truth, P2P is the fast path.
