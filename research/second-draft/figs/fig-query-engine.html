From service names to the reader’s readable set
The caller names services; the engine rewrites each one into a CTE over the real tables — filtered to what this reader may read, before the query runs
THE APP’S SQL — SERVICE NAMES ONLY
SELECT p.body, count(r.id) FROM posts p JOIN reactions r ON r.post = p.id WHERE p.id < cursor GROUP BY p.id
PROTECTED WITH AN AST — EVERY TABLE REFERENCE IS WALKED, BEFORE ANYTHING COMPILES
reject — raw node tables: any real name from the store below (documents, doc_groups, group_members, …)
reject — table functions: file() · numbers() · s3() — they surface as nameless tables
reject — services the caller isn’t granted; anything but one SELECT
round-trip — the re-emitted query is re-parsed and must come back as exactly one statement
THE BOUNDARY — THE READABLE SET IS COMPILED IN BEFORE ANY DATA MOVES
the lowering: each service name → an API-built CTE
posts (the caller’s name) AS ( SELECT doc_id, author_key, body, tags, …, group_id FROM documents -- dedup: latest row, not deleted JOIN doc_groups -- the group each doc sits in WHERE group_id IN (’g_8f…’,’g_2c…’, …) ← the readable groups, inlined AND NOT user_blacklist, group_blacklist AND NOT sharing-paused · hidden · node-banned )
No readable groups → the CTE is WHERE 1 = 0 — shape-valid, empty. An empty set, not an error.
the data
documents — the service’s rows, deduped to the latest not-deleted · doc_groups — which group each doc sits in (the CTE exposes group_id)
the readable groups — inlined as literals
computed API-side by the read gate: group_members (the reader’s memberships, roles) × group_contracts (which role grants readAll on this service), plus public / authenticated class grants
the exclusions — applied inside the CTE
user_blacklist · group_blacklist · user_group_sharing · group_hidden_docs · banned_users — a blocked or hidden author’s rows never join
ClickHouse — the node’s real tables
The caller’s SQL may not name any of these — the walk rejects them by name. The boundary CTEs are the only door.
